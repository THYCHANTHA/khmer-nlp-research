# Sample files

`synthetic_demo_dictionary.csv` is a **synthetic software demonstration** written for this repository: 14 very common
Khmer function words with generic category labels, so that the dictionary importer, the tier strategies and the Streamlit
pages can be shown working. It is **not** a research dictionary, it was **not** validated by a Khmer linguist, it is **not**
derived from any third-party resource, and no experimental result in this repository uses it. Replace it with your own
dictionary (columns `term`, `category`) through the app's upload box or `scripts/run_experiments.py --dictionary`.
