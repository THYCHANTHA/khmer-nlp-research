# Research provenance

## Origin

This work grew out of collaborative university research at the Institute of Technology of Cambodia (ITC) on Khmer stop-word
removal, TF-IDF analysis, cosine-similarity retrieval and linguistic analysis. The original project is public:
<https://github.com/Nagamiji/Stop_word_Project>. Credit for it belongs to its team; see [team contributions](team_contributions.md).

## This repository

This repository is an **independent implementation**. All code, tests, configuration and documentation here were written for it,
and its experiments use openly licensed Khmer Wikipedia text (see the [dataset card](dataset_card.md)). Ideas that originate in the
earlier project, such as grouping function words into removal tiers, are credited to it; no implementation was copied.

It is **not** an authorised continuation of the original project, and the original team has not endorsed it.

## Original materials are not redistributed

When the public repository was reviewed (2026-10-31) it declared no licence, and permission to reuse its materials has not been
established. Therefore its stop-word dictionaries, corpus, notebooks, tables and results are **not** copied into, stored in, or run by
this repository. The dictionary importer accepts any CSV, so a dictionary can be used later if its owners grant permission or another
licensed dictionary becomes available; any such permission and its scope would be recorded in
[team contributions](team_contributions.md).
